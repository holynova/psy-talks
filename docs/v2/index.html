TECH #01

价值中立与不评判 (Non-judgmental Stance)

别做啥不说教，不洗白，也不把自己的价值观塞回去。
要做啥理解选择背后的需要，同时看清后果和边界。
核心定义：暂时放下自己的道德排序，理解对方的选择如何形成；必要时仍要清楚讨论伤害、责任和边界。口诀：尊重人，评估事。
CASE 1.1我背着伴侣和同事暧昧，我知道这样不太好，但我停不下来。
‘我背着伴侣和同事暧昧，我知道这样不太好，但我停不下来。’

别做啥 错误示范

  • “你这样就是不负责任，赶紧和伴侣坦白。”

    道德审判：跳过动机、关系处境和风险，先把人推到被审判的位置。

  • “每个人都有需求，你不用自责。”

    过快洗白：把理解偷换成免责，反而无法面对行为后果。

  • “你们发展到哪一步了？对方身材怎么样？”

    猎奇追问：满足好奇而非服务于理解，容易让对方感到被消费。

要说啥 正确示范

  • “你一方面知道这段暧昧可能会伤害关系，另一方面它又像在满足某种你很久没有被满足的需要。我们可以先看看它给了你什么，也一起面对你想承担哪些后果。”

    回应 A · 保留对方的选择权

  • “你知道它可能违背你想要的关系方式，但那种被关注、被需要或重新有感觉的体验很难放手。你愿意从最想留住的部分谈起吗？”

    回应 B · 保留对方的选择权

  • “我们可以把两件事分开：这段暧昧满足了什么，以及你想为它承担什么后果。先从哪一件开始更合适？”

    回应 C · 保留对方的选择权

练习重点：既不羞辱，也不替行为开脱；把理解动机与承担责任放在同一张桌上。

CASE 1.2我不想生孩子，家里人都说我自私。
‘我不想生孩子，家里人都说我自私。’

别做啥 错误示范

  • “父母也是为你好，年纪大了可能会后悔。”

    社会规范：把咨询师的声音叠加到家庭压力上。

  • “那你就和家里彻底断掉，做自己。”

    反向劝说：把一个价值选择升级成关系决裂，替对方做了极端决定。

  • “生不生都行，没什么好聊的。”

    假中立：表面不评判，实际关闭了对方想理解自己的空间。

要说啥 正确示范

  • “你对不生育的选择似乎比较确定，但家人把它解释成‘自私’，让你开始怀疑自己。你希望在这里更清楚自己的决定，还是想练习如何回应他们？”

    回应 A · 保留对方的选择权

  • “当家人说你自私时，压力不只是意见不同，也像在动摇你对自己的判断。你自己的声音和他们的声音，哪一个现在更大？”

    回应 B · 保留对方的选择权

  • “我不需要替你决定要不要孩子；我想知道这个选择对你来说最重要的理由，以及你最担心失去什么。”

    回应 C · 保留对方的选择权

练习重点：不替对方选择生育与否，而是帮助其区分自己的价值、他人的评价和当下需要。

CASE 1.3我对孩子特别没耐心，有时真想把门一摔就走。
‘我对孩子特别没耐心，有时真想把门一摔就走。’

别做啥 错误示范

  • “你怎么能这么对孩子，你要负起责任。”

    羞耻化：责任信息可能必要，但羞耻会让人更不敢说出真实风险。

  • “当父母都这样，忍一忍就好了。”

    轻描淡写：把潜在失控风险正常化，错过安全评估。

  • “你每天冥想十分钟，耐心就会变好。”

    万能建议：在没有弄清触发点和危险程度前直接开处方。

要说啥 正确示范

  • “听起来你已经被耗到很接近极限，想离开现场可能是在避免自己继续升级。你有没有出现过伤到孩子或无法控制自己的时刻？我们先把安全和支持安排清楚，再理解是什么在反复触发你。”

    回应 A · 保留对方的选择权

  • “想摔门离开可能是在努力让自己不要失控，但我需要先知道孩子现在是否安全、你是否有过实际伤害的冲动或行为。”

    回应 B · 保留对方的选择权

  • “我们先安排一个能让你和孩子都安全的暂停方案，再慢慢看是什么把你推到极限；你身边现在有谁能接手一会儿？”

    回应 C · 保留对方的选择权

练习重点：不把‘理解’变成纵容；遇到可能伤害时，先评估安全，再讨论情绪与行动。

TECH #02

共情性理解 (Empathic Understanding)

别做啥不说‘我完全懂你’，不替对方下结论。
要做啥说出对方的体验，并加一句‘我理解得接近吗？’
核心定义：尝试理解对方此刻如何看待自己、他人和处境，再把这种理解用可被修正的语言说回来。口诀：先贴近，再确认。
CASE 1.1我最近一想到上班就胸口发紧，可我还不能辞职。
‘我最近一想到上班就胸口发紧，可我还不能辞职。’

别做啥 错误示范

  • “别想太多，都会过去的。”

    过早安慰：跳过了当下的压迫感，对方可能只剩下‘我不该这么难受’。

  • “那你就先更新简历，骑驴找马。”

    立刻解题：把复杂体验压缩成任务，尚未确认对方此刻需要被理解还是要方案。

  • “我完全懂你，这种工作谁都会受不了。”

    自信代言：把猜测说成确定，还把个人经验套在对方身上。

要说啥 正确示范

  • “听起来你一想到工作就会有很强的身体压力，但现实又让你暂时不能离开；你像是被困在‘撑不住’和‘不能走’之间。我理解得接近吗？”

    回应 A · 保留对方的选择权

  • “你很清楚辞职暂时不是选项，但身体已经先替你发出警报；一边要继续撑，一边又找不到出口。这样说有没有贴近？”

    回应 B · 保留对方的选择权

  • “当你说‘不能辞职’时，最压住你的是什么——经济、责任，还是担心离开后更糟？我想先跟着你最紧的那一部分。”

    回应 C · 保留对方的选择权

练习重点：回应同时抓住了身体体验、现实限制和两难感，并把解释权还给对方。

CASE 1.2我都三十了，还因为这点小事哭，真的很没用。
‘我都三十了，还因为这点小事哭，真的很没用。’

别做啥 错误示范

  • “三十岁哭也很正常，年龄和哭没关系。”

    讲道理：事实可能没错，但直接反驳会让自责继续留在原地。

  • “你要自信一点，别总是看到自己的缺点。”

    正能量：把情绪当成态度问题，容易制造第二层羞耻。

  • “你这是低自尊，应该做自我成长。”

    贴标签：用诊断式标签取代对这次具体体验的理解。

要说啥 正确示范

  • “你不只是哭了难受，也在因为‘我不该这样’而责备自己；好像连脆弱都变成了证明自己不够好的证据。”

    回应 A · 保留对方的选择权

  • “你似乎不只是在为这件小事哭，而是在哭的时候立刻把自己判成了‘没用的人’。”

    回应 B · 保留对方的选择权

  • “眼泪出现时，你对自己的那句评价很重；如果先不评判哭，你觉得那一刻最需要被看见的是什么？”

    回应 C · 保留对方的选择权

练习重点：先贴近自责背后的体验，不急着证明‘哭没问题’，对方才更可能继续说下去。

CASE 1.3我谁也不想见，消息也不想回。
‘我谁也不想见，消息也不想回。’

别做啥 错误示范

  • “你不能一直这样，还是要和人接触。”

    强行拉回：把保护性的退缩直接当成错误行为，可能增加抵抗。

  • “你可能抑郁了，最好马上吃药。”

    轻率诊断：信息不足，且把复杂状态直接医学化。

  • “朋友会被你伤害的，你也要考虑别人。”

    道德化：把对方的疲惫转成责任指责，关系安全感会下降。

要说啥 正确示范

  • “现在和人联系好像都需要耗掉你剩下的力气，所以你先把自己关起来，暂时不应付任何人。最近这种状态让你觉得是在休息，还是也有点失控？”

    回应 A · 保留对方的选择权

  • “不回消息像是目前唯一能让你少承受一点的办法，但它也可能让你更孤单。你现在更想保护自己，还是已经被它困住？”

    回应 B · 保留对方的选择权

  • “我先不急着判断这是休息还是退缩；最近一次你拒绝联系别人时，发生了什么？”

    回应 C · 保留对方的选择权

练习重点：承认退缩可能有保护作用，同时温和询问它的代价与程度，而不是马上命令对方社交。

TECH #03

具体化 (Concretization)

别做啥不为了证明对方夸大而追问。
要做啥回到最近一件事，问人、时、地、行为、感受。
核心定义：把时间、人物、行为、身体感受和内在想法落到可观察的片段，避免被概括词牵着走。口诀：总是变一次，大家变一个人。
CASE 1.1我总是被领导针对。
‘我总是被领导针对。’

别做啥 错误示范

  • “谁？什么时候？哪次？有没有证人？”

    连环盘问：问题堆在一起，像调查取证，容易让对方防御。

  • “你说‘总是’，真的一次例外都没有吗？”

    反驳概括：把具体化变成辩论，忽略了对方感受到的威胁。

  • “职场里被误解很正常，别太在意。”

    泛泛安慰：还没弄清事件，就用常识把它压平。

要说啥 正确示范

  • “你想到‘被针对’时，最近最先浮现的是哪一次？那次领导具体做了什么，你当时怎么理解这件事？”

    回应 A · 保留对方的选择权

  • “‘被针对’背后可能有很多经历；我们先选最近最清楚的一次，看看领导的行为、你的解释和后果分别是什么。”

    回应 B · 保留对方的选择权

  • “当你说领导针对你时，你最确定的证据是什么，又有哪些部分是你还拿不准的？”

    回应 C · 保留对方的选择权

练习重点：选一个最近片段，既看行为，也看对方赋予行为的意义。

CASE 1.2我焦虑到不行，整个人要爆炸了。
‘我焦虑到不行，整个人要爆炸了。’

别做啥 错误示范

  • “这就是惊恐发作，你需要去看医生。”

    马上诊断：可能需要评估，但一句话不足以做出诊断。

  • “按 0 到 10 分，你现在几分？”

    只量化：量表有用，但单独使用会跳过身体和情境。

  • “你每天跑步半小时就好了。”

    直接处方：未经了解就给方案，容易让对方觉得自己没被听见。

要说啥 正确示范

  • “你说‘要爆炸了’，这种感觉通常在什么时候升起来？身体最明显的地方是哪儿，脑子里会出现什么画面或担心？”

    回应 A · 保留对方的选择权

  • “听起来‘爆炸’不只是一个比喻，身体和脑子都像被推到警报状态。它通常由什么触发，又会把你带向什么行为？”

    回应 B · 保留对方的选择权

  • “我们先把强度和安全弄清楚：你现在能让自己停下来吗？最近有没有伤害自己或他人的冲动？”

    回应 C · 保留对方的选择权

练习重点：把强烈但模糊的词拆成时间、身体与想法，为后续评估和干预提供材料。

CASE 1.3他们都不理解我。
‘他们都不理解我。’

别做啥 错误示范

  • “把你认识的所有人都列出来，我们逐个分析。”

    扩大调查：范围过大，容易让会谈失去焦点。

  • “你父母肯定从小就否定你。”

    代入关系：把未说出的家庭史当成事实。

  • “怎么可能所有人都不理解你？总有人关心你吧。”

    轻率否定：为了纠正逻辑而忽略孤立感。

要说啥 正确示范

  • “你说‘他们’时，脑中最先想到的是谁？最近哪一次让你最强烈地觉得‘他没有理解我’？”

    回应 A · 保留对方的选择权

  • “你说‘他们不理解’时，似乎带着反复解释仍然无效的疲惫。最近哪一次最让你确认这一点？”

    回应 B · 保留对方的选择权

  • “你希望他们理解的是你的感受、你的决定，还是你需要他们做的具体改变？”

    回应 C · 保留对方的选择权

练习重点：从一个重要关系和一次典型事件开始，孤立感才有机会被准确描述。

TECH #04

情感反映 (Reflection of Feeling)

别做啥不武断说‘你就是……’，不抢着让对方开心。
要做啥用‘似乎、好像、我在想’表达情绪观察。
核心定义：从语言、语气、表情和身体反应中捕捉情绪，用试探性语言帮助对方辨认正在发生什么。口诀：命名不盖章，猜测留出口。
CASE 1.1对方说没什么，但眼眶发红、停顿很久。
对方说‘没什么’，但眼眶发红、停顿很久。

别做啥 错误示范

  • “好，那我们继续下一个问题。”

    忽略信号：放过了重要的非语言信息，也可能让对方觉得自己不值得被注意。

  • “你其实非常悲伤，只是不敢承认。”

    武断命名：把观察变成结论，容易引起反驳。

  • “别哭了，想点开心的事。”

    强行提振：把眼泪当作需要立刻停止的故障。

要说啥 正确示范

  • “你说‘没什么’，但刚才停了很久，眼睛也红了。我在想，那里可能有一些难过或不容易说出的东西；如果我猜错了，你可以纠正我。”

    回应 A · 保留对方的选择权

  • “我看到你说没什么时眼睛红了，但我不想替你决定那是什么。你此刻更想继续讲，还是先停下来感受一下？”

    回应 B · 保留对方的选择权

  • “也许这里有一部分还没准备好被说出来；我们可以不逼它出现，只从你愿意说的最外围开始。”

    回应 C · 保留对方的选择权

练习重点：把语言与非语言放在一起，使用低确定性的词，既不忽略也不强行解释。

CASE 1.2他一直没回消息，我知道他可能只是忙，但我就是坐立不安。
‘他一直没回消息，我知道他可能只是忙，但我就是坐立不安。’

别做啥 错误示范

  • “他忙就不会回，你别自己吓自己。”

    理性压制：解释事实不等于接住等待中的不安。

  • “你这是典型的焦虑型依恋。”

    贴标签：理论标签抢走了当下体验，且未必准确。

  • “你再发一条，直接问清楚。”

    立刻解决：没有先判断对方想处理情绪还是想决定行动。

要说啥 正确示范

  • “你一边知道‘他可能只是忙’，一边又被等待和不确定性牵着走，像是很难把注意力从这条消息上移开。”

    回应 A · 保留对方的选择权

  • “等待把你的注意力牢牢绑在他有没有回复上，理智知道一种可能，身体却在经历另一种不确定。此刻最难受的是被忽略的感觉，还是不知道会发生什么？”

    回应 B · 保留对方的选择权

  • “我们可以先分开事实和想象：目前确定知道什么？你脑中最担心的画面是什么？”

    回应 C · 保留对方的选择权

练习重点：反映理智与情绪同时存在的拉扯，而不是只支持其中一边。

CASE 1.3我生气的不是他，是我自己怎么又搞砸了。
‘我生气的不是他，是我自己怎么又搞砸了。’

别做啥 错误示范

  • “别生自己的气，这解决不了问题。”

    阻止生气：把情绪当成需要消灭的障碍。

  • “你其实还是在生他的气。”

    替换重点：不接受对方对自己情绪的描述。

  • “你是在惩罚自己，因为童年被父母否定。”

    深度解读：可能有理论假设，但此刻证据不足且过于跳跃。

要说啥 正确示范

  • “听起来这里面有两层：事情没按你的期待发展让你生气，而更刺痛你的可能是对自己失望，甚至觉得又证明了‘我会搞砸’。”

    回应 A · 保留对方的选择权

    回应 B · 保留对方的选择权

    回应 C · 保留对方的选择权

别做啥不强行积极，不用一个优点盖住全部痛苦。

TECH #15

选择与小步行动 (Small-step Action)

别做啥不布置大计划，不把未完成变成人格证据。
要做啥提供几个选项，让对方选最小可行的一步。

  • “我们先不做完整计划：把事情分成必须、可以推迟、可以求助三类，你想从哪类开始？”

TECH #16

真诚与边界 (Congruence & Boundaries)

别做啥不靠过度自曝换亲近，不用规则挡掉情绪。
要做啥简短说明边界，再提供合适替代。
核心定义：用清楚、稳定、不过度表演的方式在场；能承认不知道，也能说明咨询关系的规则。口诀：真诚不越界，边界不冷脸。
CASE 3.1你是不是也被父母控制过？不然你不会懂。
‘你是不是也被父母控制过？不然你不会懂。’

别做啥 错误示范

  • “我爸妈也控制我，我给你讲讲我当年的故事。”

    过度自曝：咨询焦点从来访者转到咨询师，还可能形成比较。

  • “这是我的隐私，我不回答。”

    冷硬拒绝：边界虽在，但语气可能让对方感到被挡开。

  • “我当然经历过，所以我特别懂你。”

    虚假共鸣：为了建立关系而捏造或夸大相似经历。

要说啥 正确示范

  • “我没有和你完全相同的经历，也不想假装自己完全懂。但我听见你很在意‘只有经历过的人才有资格理解你’；我们可以从你被控制的具体时刻开始。”

    回应 A · 保留对方的选择权

  • “你似乎在确认我能不能真正靠近这段经历，而不是只用专业话回应。即使我没有同样经历，我愿意跟着你讲它怎样影响你。”

    回应 B · 保留对方的选择权

  • “我可以不谈我的私人经历，但我想理解：当我没有相同背景时，你最担心我会漏掉什么？”

    回应 C · 保留对方的选择权

练习重点：承认差异不等于失去共情，反而比虚假的相似更可靠。

CASE 3.2来访者迟到 25 分钟后说：最近太乱了，别计较这一次。
来访者迟到 25 分钟后说：‘最近太乱了，别计较这一次。’

  • “你总是这样不尊重别人，今天不用谈了。”

TECH #17

别做啥不诊断、不倾销技巧、不用免责声明逃避帮助。
要做啥征得同意，给有限信息，说明边界和不确定性。
核心定义：在对方需要时提供清楚的信息、资源或建议，并说明不确定性；尽量把选择权和适用性判断留给对方。口诀：先问要不要，再给一两个。
CASE 3.1我总是失眠，要不要去看精神科？
‘我总是失眠，要不要去看精神科？’

别做啥 错误示范

  • “你应该是抑郁症，去开药吧。”

  • “不用看医生，睡眠问题自己调一调就好。”

    绝对劝阻：可能延误需要专业评估的情况。

  • “我不是医生，不能给建议，你自己决定。”

    免责声明堆砌：回避了对方真正需要的基本信息。

要说啥 正确示范

  • “可以一起了解一下。持续失眠、白天功能受影响，或伴随明显情绪和安全问题时，找精神科或身心科做评估是一个选项；我不能替你诊断。你想先了解就诊流程，还是先看看失眠持续多久、怎样影响你？”

    回应 A · 保留对方的选择权

  • “失眠已经影响白天功能或持续存在时，精神科／身心科评估可以帮助排除需要处理的因素；我可以陪你整理就诊时要带的信息，但不能代替诊断。”

    回应 B · 保留对方的选择权

  • “如果你愿意，我们先记录持续时间、入睡／早醒、白天影响和伴随症状，再决定是否预约；若出现安全风险，要优先求助。”

    回应 C · 保留对方的选择权

练习重点：给出有限且可行动的信息，同时明确评估边界，不把建议说成诊断。

CASE 3.2我一紧张就喘不过气，有没有什么当下能做的？
‘我一紧张就喘不过气，有没有什么当下能做的？’

别做啥 错误示范

  • “马上做 4-7-8 呼吸，每次都必须坚持。”

    一把梭处方：未经确认就给单一方法，还把效果责任推给执行。

  • “呼吸、冥想、冷水洗脸、运动、写日记都试试。”

    技巧倾销：选项过多，在紧张时反而增加负担。

  • “你要自己学会调节情绪。”

    完全不提供：把求助说成能力不足。

要说啥 正确示范

  • “如果你愿意，我可以先介绍一个很短的做法：把呼气放慢、脚踩地面，注意眼前五样东西。它不是替代评估，也不一定适合所有人；你现在更想试一个一分钟的练习，还是先描述这种喘不过气的情况？”

    回应 A · 保留对方的选择权

  • “这种喘不过气很吓人；我们可以先确认是否有胸痛、晕厥等需要急诊的情况，再决定是否做一分钟的放慢呼气练习。”

    回应 B · 保留对方的选择权

  • “我可以陪你把脚踩地、看见周围五样东西；如果症状严重、首次出现或不确定是身体问题，请立即联系急救或医疗服务。”

    回应 C · 保留对方的选择权

练习重点：征得同意、只给一个低负担选项，并保留对身体症状进行评估的空间。

CASE 3.3我们聊的内容会不会被别人知道？
‘我们聊的内容会不会被别人知道？’

别做啥 错误示范

  • “绝对不会，任何情况都不会告诉别人。”

    绝对保密：忽略专业、法律和安全相关的例外。

  • “你放心，都是保密的。”

    模糊保证：没有让对方知道保密如何运作。

  • “这是法律规定，你不需要知道细节。”

    法律吓阻：把合理的知情需要挡在规则之外。

要说啥 正确示范

  • “一般情况下，你分享的内容会被保密；开始前应说明记录、督导以及涉及人身安全时可能需要采取保护措施的边界。你最担心哪一种信息被谁知道？我们可以把具体规则讲清楚。”

    回应 A · 保留对方的选择权

  • “保密通常有边界，包括记录、督导以及人身安全风险等例外；我可以先把适用于你的规则逐条说明，再听你最担心的部分。”

    回应 B · 保留对方的选择权

  • “你问保密可能是在确认这里是否安全。除了法定或安全相关的例外，哪些内容会让你最担心被别人知道？”

    回应 C · 保留对方的选择权

练习重点：保密是知情同意的一部分，不能用绝对承诺换取表面安心。

TECH #18

风险筛查与转介 (Risk Screening & Referral)

别做啥不鸡汤、不忽略、不承诺绝对保密或独自扛危机。
要做啥直接评估想法、计划、手段、时间和现实支持。
核心定义：遇到自伤、自杀、暴力、严重失控或超出能力范围的情况，直接、平静地评估风险，启动合适的现实支持和专业转介。口诀：听到危险，先问计划；超出能力，马上连接。
CASE 3.1我最近真的不想活了。
‘我最近真的不想活了。’

别做啥 错误示范

  • “别这样想，人生还有很多美好的事。”

    鸡汤安慰：没有回答危险程度，也可能让对方觉得不能再说。

  • “我们先回到你和伴侣的矛盾。”

    忽略信号：跳过可能需要立即处理的安全问题。

  • “天啊，你怎么能这样想？我马上通知所有人！”

    灾难化惊叫：可能让对方害怕、撤回信息，且未先做基本评估。

要说啥 正确示范

  • “谢谢你直接告诉我。我需要认真确认：你现在有没有想过要怎么做、什么时候做，或已经准备了什么东西？你此刻是一个人吗？如果有马上伤害自己的危险，我们先联系当地急救或危机服务，并让可信任的人陪在你身边。”

    回应 A · 保留对方的选择权

  • “我很重视你说‘不想活了’，现在先确认危险程度：你有没有具体计划、时间、手段，身边是否有人能陪你？”

    回应 B · 保留对方的选择权

  • “如果你已经准备实施或无法保证安全，请先联系当地急救／危机服务，让可信任的人现在陪着你；我们再继续谈痛苦从何而来。”

    回应 C · 保留对方的选择权

练习重点：平静而直接地问计划、时间、手段和当下环境；安全优先于继续做普通探索。

CASE 3.2我上周割过自己一次，没想死，就是想让脑子停下来。
‘我上周割过自己一次，没想死，就是想让脑子停下来。’

别做啥 错误示范

  • “你怎么能做这种事？你要为自己负责。”

    震惊责备：羞耻会让后续风险更难被发现。

  • “我不会告诉任何人，你放心。”

    秘密承诺：在安全风险未评估前做绝对保密承诺。

  • “你去找心理医生吧。”

    泛泛转介：没有确认现在是否仍有冲动、伤口是否需要处理。

要说啥 正确示范

  • “谢谢你说出来。你当时是想让痛苦停下来，而不是想死；我还需要确认现在有没有再次伤害自己的冲动、伤口是否已经得到处理，以及今晚谁能陪你。我们一起把安全安排好，再理解这个行为在帮你应对什么。”

    回应 A · 保留对方的选择权

  • “谢谢你把这件事说出来。我们先确认伤口是否需要医疗处理、现在是否还想再次伤害自己，以及今晚能否有人陪你。”

    回应 B · 保留对方的选择权

  • “自伤可能是在让难以承受的痛苦暂时停下来，但安全要先于解释；我们一起做一份今天能执行的保护计划，再理解触发点。”

    回应 C · 保留对方的选择权

练习重点：不把自伤意图简单等同于自杀意图，但仍要具体评估当前风险与身体安全。

CASE 3.3来访者出现严重幻听，要求你保证只靠谈话就能解决。
来访者出现严重幻听，要求你保证只靠谈话就能解决。

别做啥 错误示范

  • “可以，我陪你聊几次就会好。”

    能力冒充：隐瞒能力边界，可能延误必要的医疗支持。

  • “你这是精神病，我没法和你聊。”

    贴标签驱赶：污名化并切断关系。

  • “你不要理它们，假装没听见就好。”

    随意指示：把严重症状简化成意志控制。

要说啥 正确示范

  • “你希望通过谈话得到帮助，我会认真陪你了解这些声音带来的影响；同时，这种症状需要由具备相应资质的精神科专业人员评估。我们可以一起安排转介，并确认你现在是否能保持自己和他人的安全。”

    回应 A · 保留对方的选择权

  • “这些声音给你带来的影响值得认真对待；我不能靠一般对话判断原因，需要尽快连接精神科评估，同时确认你是否能保持安全。”

    回应 B · 保留对方的选择权

  • “我们可以一起安排转介并记录声音出现的时间、内容和你受到的影响；如果它命令你伤害自己或别人，请立即联系急救／危机服务并让可信任的人陪同。”

    回应 C · 保留对方的选择权

练习重点：透明说明能力边界，维持尊重与连续支持，同时连接更合适的专业资源。

好的回应不一定漂亮，但应该让对方更接近自己的经验，而不是更接近你的答案。
